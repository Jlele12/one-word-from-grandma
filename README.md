If you asked a grandma what she thinks of AI, she would text back one word: **nosy**.

`main.py` writes exactly that one word (1-30 chars, UTF-8) to `/output/entry.txt`.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
